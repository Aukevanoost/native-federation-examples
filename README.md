Angular Native Federation orchestrator examples

This demo application demonstrates how native federation orchestrators can be leveraged ito load remotes into any web application. The project showcases three orchestrators:

1. **Simple:** bare-bones orchestrator
2. **Config:** An orchestrator which passes environment variables to the remotes.
3. **Dev:** An experimental orchestrator which loads 2 remotes from the tractor store.

## 🏗️ Architecture Overview

This project uses **Native Federation** to create standalone micro frontends that can be dynamically loaded and integrated into any host application. The architecture follows the micro frontend pattern where each component is:

- **Independently deployable**
- **Technology agnostic** (can be consumed by any framework)
- **Self-contained** with its own dependencies and configuration

> Read more about native federation here: https://github.com/topicusonderwijs/vanilla-native-federation/blob/main/docs/architecture.md
